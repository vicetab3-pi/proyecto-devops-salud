# Plataforma de Reserva de Horas Médicas - Proyecto DevOps

Servicio web estático contenedorizado con Nginx (`nginx:alpine`) y Docker Compose para garantizar un entorno reproducible y seguro en el rubro salud.

## Requisitos Previos
- Git
- Docker Engine / Docker Desktop o GitHub Codespaces

## Instalación y Ejecución
1. Clonar el repositorio:
   ```bash
   git clone [https://github.com/TU_USUARIO/proyecto-devops-salud.git](https://github.com/TU_USUARIO/proyecto-devops-salud.git)
   cd proyecto-devops-salud
